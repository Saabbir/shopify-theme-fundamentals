**TL;DR:** Everything about sections, from what one is to the most advanced patterns and performance considerations.

This chapter is a complete, standalone reference on sections — it starts from zero and builds all the way up to advanced territory, so it works whether this is the first page you've ever read on this site or the fiftieth. It assumes you know HTML, CSS, and JavaScript, same as the rest of this site, but nothing Shopify-specific beyond that.
